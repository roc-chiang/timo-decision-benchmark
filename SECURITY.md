# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data leak in this repository, please do not open a public issue.

Instead, please send an email directly to **security@timobuy.com**.

We will acknowledge receipt within 48 hours and provide an estimated timeline for evaluation and remediation.
